# 记小账 - 前端项目

## 📁 项目结构

```
003.前端代码（前端工程师）/
├── index.html              # 入口文件（自动跳转到首页）
├── README.md               # 项目说明文档
└── src/
    ├── css/                # 样式文件
    │   └── base.css        # 全局样式（CSS变量、通用类）
    ├── js/                 # JavaScript文件
    │   ├── utils.js        # 工具函数（Toast、Modal、数据格式化）
    │   └── navigation.js   # 导航组件
    └── pages/              # 页面文件
        ├── home.html       # 首页（月度概览、快捷记账、最近记录）
        ├── add.html        # 记账页（金额输入、分类选择、数字键盘）
        ├── bills.html      # 账单页（列表、筛选、搜索、编辑删除）
        ├── stats.html      # 统计页（饼图、趋势图、月度对比）
        ├── budget.html     # 预算页（环形图、分类预算、提醒设置）
        └── profile.html    # 我的页（个人信息、设置、数据管理）
```

## 📱 功能说明

### 首页 (home.html)
- 顶部显示日期、问候语、用户头像
- 月度支出概览卡片（渐变色）
- 今日收支统计卡片
- 预算进度条（带预警提示）
- 快捷记账分类网格（8个分类）
- 最近记录列表
- 悬浮记账按钮（FAB）
- 底部导航栏（5个Tab）

### 记账页 (add.html)
- 支出/收入类型切换
- 大字号金额显示
- 分类选择（8个分类，带图标）
- 日期选择（今天/昨天/自定义）
- 支付方式选择
- 数字键盘（支持小数）
- 备注输入
- 保存成功弹窗

### 账单页 (bills.html)
- 月份选择器
- 搜索框（关键词搜索）
- 类型筛选（全部/支出/收入）
- 分类标签筛选
- 按日期分组展示
- 编辑/删除操作
- 删除撤回提示（Toast）

### 统计页 (stats.html)
- 收支概览卡片
- ECharts饼图（分类占比）
- ECharts折线图（每日趋势）
- ECharts柱状图（月度对比）
- 智能提醒列表

### 预算页 (budget.html)
- ECharts环形图（预算使用率）
- 分类预算列表（带进度条）
- 预算提醒设置（开关）
- 提醒记录列表
- 调整预算弹窗

### 我的页 (profile.html)
- 用户信息卡片（头像、昵称、统计）
- 账户信息（手机号、邮箱、密码）
- 个性化设置（主题、提醒时间、默认分类）
- 数据管理（备份、同步、导出、撤回）
- 关于（帮助反馈、版本信息）

## 🛠 技术栈

- **HTML5**: 语义化标签
- **CSS3**: Tailwind CSS + 自定义样式
- **JavaScript**: 原生 JS（ES6+）
- **图表**: ECharts 5.x
- **图标**: Iconify (Phosphor Icons)

## 🚀 使用方法

1. 直接在浏览器中打开 `index.html`
2. 或打开 `src/pages/home.html`
3. 所有页面通过底部导航栏相互跳转
4. 数据存储在内存中（刷新后重置）

## 📝 开发规范

### 文件命名
- 页面文件：小写英文 + `.html` 后缀
- 样式文件：小写英文 + `.css` 后缀
- JS文件：小写英文 + `.js` 后缀
- 使用连字符分隔单词（如：`base.css`）

### CSS 规范
- 使用 CSS 变量定义颜色、圆角、阴影
- 组件样式写在对应页面内
- 全局样式放在 `base.css`
- 使用 Tailwind CSS 工具类

### JavaScript 规范
- 工具函数放在 `utils.js`
- 页面逻辑写在对应页面的 `<script>` 中
- 使用 `DOMContentLoaded` 初始化
- 事件处理使用行内 `onclick`（原型阶段）

### 注释规范
- 页面标题使用 `<!-- 区域名 -->` 注释
- 重要逻辑添加行内注释
- 不使用行尾注释

## 🔄 与原版对比

| 项目 | 原版 | 新版 |
|-----|------|------|
| 文件组织 | 平铺6个HTML | 分层结构（css/js/pages） |

| 数据 | 硬编码 | 动态渲染 |

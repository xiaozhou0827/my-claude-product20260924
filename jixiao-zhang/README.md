# 记小账 - 个人财务管理网站

## 项目概述
基于 PRD 文档开发的个人日常消费记录与管理工具，采用粉嫩可爱风格设计。

## 技术栈
- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite 8.3.0
- **样式方案**: Tailwind CSS 4.x
- **图表库**: Recharts 3.x
- **图标库**: Lucide React

## 项目结构
```
jixiao-zhang/
├── src/
│   ├── components/      # 组件
│   │   ├── AddExpenseModal.tsx  # 记账弹窗

│   │   └── useLocalStorage.ts   # 本地存储管理
│   ├── pages/           # 页面组件
│   │   ├── HomePage.tsx         # 首页（记账入口+概览）
│   │   ├── ExpenseList.tsx      # 账单管理页
│   │   ├── StatsPage.tsx        # 统计分析页
│   │   └── BudgetPage.tsx       # 预算管理页

```

## 配色方案（粉嫩可爱风）

- 浅樱粉 `#FFE4E9` - 背景区块
- 奶油白 `#FFF9F9` - 页面主背景

- 收入/预算剩余：薄荷绿 `#A8E6CF`

## 核心功能

### 1. 记账功能
- 快速记账（金额、分类、日期、备注、支付方式）
- 快捷记账入口（首页悬浮按钮）
- 历史分类记忆（自动填充上次选择）

### 2. 账单管理
- 账单列表（按日期分组展示）
- 多维度筛选（分类、日期、关键词搜索）
- 编辑/删除功能（支持批量操作）

### 3. 统计分析
- 月度支出概览（总支出、总收入、结余）
- 分类占比饼图
- 近30天支出趋势图
- 同比/环比分析

### 4. 预算管理
- 月度总预算设置
- 分类预算设置
- 实时进度条（绿→黄→红）
- 超支预警提醒

### 5. 个人中心
- 账户信息设置
- 主题切换（浅色/深色）
- 提醒时间设置
- 数据导出（Excel/CSV）
- 数据备份与恢复

## 数据持久化
- 使用 localStorage 本地存储
- 数据加密存储（敏感信息）
- 支持数据导出备份

## 运行方式

### 开发模式
```bash
cd jixiao-zhang
npm install
npm run dev
```
访问 http://localhost:3000

### 生产构建
```bash
npm run build
```
产物位于 `dist/` 目录

### 预览构建结果
```bash
npm run preview
```

## 设计亮点

1. **极简操作**: 3秒完成一笔消费记录
2. **可视化洞察**: 清晰的图表展示消费趋势
3. **习惯养成**: 每日提醒，培养记账意识
4. **粉嫩风格**: 治愈系配色，使用体验轻松愉快
5. **圆角设计**: 大圆角卡片，柔和友好

## 下一步优化建议

1. **云端同步**: 添加后端服务，实现多设备数据同步
2. **智能分析**: 基于消费数据提供理财建议
3. **社交功能**: 家庭共享账本，共同管理家庭财务
4. **账单导入**: 支持支付宝/微信账单自动解析
5. **游戏化**: 打卡奖励、成就系统，提升用户粘性

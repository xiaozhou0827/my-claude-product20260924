# 记小账 - 使用指南

## 🌐 访问地址

开发服务器已启动：http://localhost:3000

## 📱 主要功能

### 1. 登录注册系统（新增）
- **用户注册**：输入用户名（至少3字符）、密码（至少6字符）、昵称（可选）
- **用户登录**：用户名+密码认证
- **会话管理**：localStorage 持久化登录状态，刷新不丢失
- **退出登录**：清除会话，返回登录页
- **数据隔离**：每个用户独立存储数据

### 2. 首页
- 显示今日支出、收入、本月结余、预算进度
- 快捷记账按钮（餐饮、交通、购物、娱乐）
- 最近收支记录展示
- 个性化问候（根据时间显示上午/下午/晚上好）

### 3. 账单管理
- 查看所有账单记录
- 按分类筛选（餐饮/交通/购物/娱乐/医疗/教育/居住/其他）
- 按日期筛选（全部/今天/昨天/自定义）
- 关键词搜索（支持备注和分类搜索）
- 点击记录可查看详情/编辑

### 4. 统计分析
- 月度支出概览（总支出、总收入、结余）
- 分类占比饼图
- 30天收支趋势面积图
- 可视化数据分析

### 5. 预算管理
- 设置月度总预算
- 设置各分类预算
- 实时进度条（绿→黄→红预警）
- 超支预警提示

### 6. 个人中心
- 查看统计数据（总笔数、总支出、总收入）
- 编辑个人资料
- 设置提醒时间
- 导出数据备份
- 清空数据（需确认）
- 退出登录

## 🎨 设计特点

- **粉嫩可爱风格**：樱花粉主色调，温暖治愈
- **玻璃态效果**：半透明导航栏，现代感强
- **渐变卡片**：彩色渐变统计卡片，视觉丰富
- **流畅动画**：滑入、缩放、淡入等过渡效果
- **大圆角设计**：12-16px圆角，柔和友好
- **数字字体**：等宽字体显示金额，清晰易读

## 🚀 项目信息

- 技术栈：React 18 + TypeScript + Vite + Tailwind CSS
- 图表库：Recharts
- 图标库：Lucide React
- 本地存储：localStorage（每个用户独立数据）
- 项目目录：d:/CLAUDE-MY-PRODUCT/jixiao-zhang/

## 💾 数据说明

所有数据存储在浏览器 localStorage 中，按用户名独立分隔。
- 用户数据：`jixiao-zhang-users`
- 当前登录：`jixiao-zhang-current-user`
- 用户数据：`jixiao-zhang-data-{username}`

清除浏览器数据会导致记录丢失。建议定期导出数据备份。

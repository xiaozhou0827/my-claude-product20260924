## 一、产品概述

### 1.1 产品名称
**记小账**（Personal Expense Tracker）

### 1.2 产品定位
一款轻量级、易用的个人日常消费记录与管理工具，帮助用户轻松追踪每日收支，养成良好理财习惯。

### 1.3 核心价值
- **极简操作**：3秒完成一笔消费记录
- **清晰洞察**：可视化展示消费趋势与占比
- **习惯养成**：每日提醒，培养记账意识

### 1.4 目标用户
| 用户类型 | 特征 | 需求痛点 |
|---------|------|---------|
| 职场新人 | 22-30岁，有稳定收入 | 不知钱花在哪里，缺乏理财概念 |
| 学生群体 | 18-25岁，生活费有限 | 月光族，想控制开支但坚持不下来 |
| 家庭主理人 | 25-45岁，管理家庭财务 | 需要清晰的家庭支出明细 |

## 二、功能需求

### 2.1 核心功能模块

#### 模块一：记账（最高优先级）
**功能描述**：快速记录每一笔消费

**功能点**：
1. **手动记账**
   - 金额输入（支持整数、小数）
   - 分类选择（餐饮、交通、购物、娱乐、医疗、教育等）
   - 日期选择（默认今天）
   - 备注填写（可选）
   - 支付方式（现金、微信、支付宝、信用卡等）

2. **快捷记账**
   - 首页悬浮按钮，一键进入记账页面
   - 常用分类快捷入口
   - 历史分类记忆（自动填充上次选择的分类）

3. **批量记账**（后期迭代）
   - 导入账单（支付宝/微信账单解析）

#### 模块二：账单管理
**功能描述**：查看和管理所有记账记录

**功能点**：
1. **账单列表**
   - 按时间倒序排列
   - 支持按日期、分类筛选
   - 搜索功能（按备注关键词）

2. **账单编辑/删除**
   - 修改金额、分类、备注
   - 删除记录（支持批量删除）
   - 撤回删除（7天内）

3. **账单导入/导出**
   - 导出Excel/CSV格式
   - 导入银行/支付平台账单

#### 模块三：统计分析
**功能描述**：可视化展示消费数据

**功能点**：
1. **支出概览**
   - 今日/本周/本月支出统计
   - 收入支出对比（结余计算）

2. **分类占比**
   - 饼图展示各类消费占比
   - 同比/环比分析（上月对比）

3. **趋势图表**
   - 每日支出折线图
   - 月度支出柱状图
   - 年度消费总结

4. **智能提醒**
   - 超支预警（设置月度预算后）
   - 大额消费提醒
   - 周期性支出提醒（订阅、房租等）

#### 模块四：预算管理
**功能描述**：设置并跟踪消费预算

**功能点**：
1. **月度预算**
   - 设置月度总支出预算
   - 按分类设置预算（餐饮预算、娱乐预算等）

2. **预算进度**
   - 实时显示预算使用进度
   - 进度条可视化（绿→黄→红）

3. **预算提醒**
   - 使用达80%时提醒
   - 超支时强制提醒

#### 模块五：个人中心
**功能描述**：账户设置与个性化配置

**功能点**：
1. **账户信息**
   - 用户名/头像设置
   - 绑定邮箱/手机号

2. **个性化设置**
   - 主题切换（浅色/深色模式）
   - 提醒时间设置
   - 默认分类设置

3. **数据管理**
   - 本地数据备份
   - 云端同步（可选）
   - 数据导出

---

### 2.2 非功能性需求

| 需求类型 | 具体要求 |
|---------|---------|
| 性能 | 首屏加载<1秒，操作响应<200ms |
| 兼容性 | 支持iOS 12+、Android 8.0+ |
| 数据安全 | 本地数据加密存储，敏感信息不上传 |
| 易用性 | 新用户30秒内完成第一笔记账 |
| 稳定性 | 崩溃率<0.1% |

## 三、用户故事

### 3.1 核心场景

**场景一：日常记账**
```
作为用户，
我希望在消费后立即记录，
方便我清楚每一笔钱的去向。

操作步骤：
1. 打开应用
2. 点击"+"按钮
3. 输入金额（如：35.5）
4. 选择分类（如：餐饮）
5. 点击"保存"
```

**场景二：查看月度账单**
```
作为用户，
我希望在月底查看我的消费统计，
方便我了解钱都花到哪里去了。

操作步骤：
1. 进入"统计"页面
2. 选择月份（如：2026年9月）
3. 查看总支出、分类占比、消费趋势
```

**场景三：控制消费**
```
作为用户，
我希望设置月度预算并收到提醒，
方便我控制不必要的开支。

操作步骤：
1. 进入"预算"页面
2. 设置月度预算（如：3000元）
3. 系统自动跟踪进度
4. 达到80%时收到推送提醒
```

```
记小账

│   ├── 快速记账
│   ├── 今日收支
│   └── 最近记录
├── 账单（账单列表）
│   ├── 全部账单
│   ├── 按日期筛选
│   ├── 按分类筛选
│   └── 搜索
├── 统计（数据可视化）
│   ├── 支出概览
│   ├── 分类分析
│   ├── 趋势图表
│   └── 月度对比
├── 预算（预算管理）
│   ├── 月度预算
│   ├── 分类预算
│   └── 预算提醒
└── 我的（个人中心）
    ├── 账户设置
    ├── 提醒设置
    ├── 主题设置
    └── 数据管理
```

### 4.2 技术选型（建议）

| 层次 | 技术选型 | 说明 |
|-----|---------|------|
| 前端 | Flutter / React Native | 跨平台，一套代码多端运行 |
| 后端 | Node.js + Express | 轻量级，开发效率高 |
| 数据库 | SQLite（本地）+ MongoDB（云端） | 本地优先，云端可选同步 |
| 认证 | JWT | 轻量级身份验证 |
| 推送 | 极光推送 / Firebase Cloud Messaging | 预算提醒、周期提醒 |

## 五、界面设计建议

### 5.1 设计风格
- **整体风格**：粉嫩、可爱、清新、治愈系
- **主色调**：樱花粉系（温暖甜美）
- **辅色调**：奶油白、薰衣草紫、薄荷绿（点缀）
- **字体**：圆润无衬线字体（如 PingFang SC、Nunito），字号偏大，圆角卡片
- **图标**：圆润线性图标，带描边，配色柔和
- **按钮**：大圆角（12-16px），轻微渐变，带阴影层次

## 六、成功指标

### 6.1 核心指标（North Star Metric）
- **日活跃记账用户数**：日均完成至少1笔记账的独立用户数

### 6.2 关键指标

| 指标类别 | 指标名称 | 目标值 |
|---------|---------|-------|
| 用户增长 | 新增注册用户数 | 首月1000人 |
| 用户留存 | 次日留存率 | >40% |
| 用户留存 | 7日留存率 | >20% |
| 用户留存 | 30日留存率 | >10% |
| 使用深度 | 日均记账笔数 | ≥3笔/人 |
| 使用深度 | 平均使用时长 | ≥2分钟/次 |
| 用户满意度 | NPS评分 | >30 |
| 商业指标 | 付费转化率（如有） | >5% |

## 七、里程碑规划

### Phase 1：MVP版本（4周）
**目标**：核心记账功能上线，验证用户需求

| 周次 | 任务 | 交付物 |
|-----|------|-------|
| Week 1 | 需求细化、UI设计 | 原型图、设计稿 |
| Week 2 | 前端开发（首页、记账页） | 可交互原型 |
| Week 3 | 后端开发、数据库设计 | API接口、数据库 |
| Week 4 | 联调测试、Bug修复 | MVP版本 |

**MVP功能范围**：
- 手动记账（基础分类）
- 账单列表
- 今日/本月支出统计
- 本地数据存储

### Phase 2：完善版（6周）
**目标**：功能完善，提升用户体验

| 周次 | 任务 | 交付物 |
|-----|------|-------|
| Week 5-6 | 统计分析模块 | 图表可视化 |
| Week 7-8 | 预算管理模块 | 预算设置与提醒 |
| Week 9-10 | 个性化设置 | 主题、提醒配置 |
| Week 11-12 | 测试优化、发布 | 正式版本 |

**新增功能**：
- 分类占比分析
- 趋势图表
- 月度预算
- 深色模式
- 数据导出

### Phase 3：增长版（持续迭代）
**目标**：用户增长、功能扩展

**规划功能**：
- 云端同步（多设备数据一致）
- 账单导入（支付宝/微信账单解析）
- 智能分析（消费习惯洞察）
- 社交功能（家庭共享账本）
- 理财建议（基于消费数据的建议）

## 八、风险评估

| 风险项 | 可能性 | 影响程度 | 应对策略 |
|-------|-------|---------|---------|
| 用户坚持不下来 | 高 | 高 | 游戏化设计、打卡奖励、社交监督 |
| 竞品众多，差异化不足 | 中 | 中 | 聚焦极简体验、本地优先、隐私保护 |
| 数据安全问题 | 低 | 高 | 本地加密、端到端加密同步 |
| 功能过于简单，用户粘性低 | 中 | 中 | 持续迭代智能分析、预算管理等功能 |

## 九、附录

### 9.1 竞品分析

| 产品 | 优点 | 缺点 | 差异化机会 |
|-----|------|------|-----------|
| 随手记 | 功能全面、分类详细 | 广告多、操作复杂 | 极简体验、无广告 |
| 鲨鱼记账 | 界面简洁、上手快 | 功能单一、无同步 | 增加云同步、智能分析 |
| MoneyWiz | 专业、多平台 | 学习成本高、收费 | 降低门槛、免费基础版 |
